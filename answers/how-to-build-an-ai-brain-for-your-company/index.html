How do I build an AI brain for my company without exposing client files?

Build one private system that answers from your company’s own documents, and hold it to five rules: follow the permissions you already have, keep sensitive files out, require a source for every answer, keep one approved copy of each shared prompt, and cap what a run can cost. Start with one team and one folder.

What an AI brain is

It’s a system that reads your company’s own files (shared drives, email, call notes, old proposals) and answers questions in plain English. Someone asks “What did we tell this client last year?” and gets an answer with the file and page it came from.

Two things separate it from pasting documents into a public chat window. The documents stay somewhere you control, and the system knows who is asking.

The five rules

  1. Use the permissions you already have. Access follows the folder rights already set in SharePoint or Google Drive. If someone can’t open a file today, the AI shouldn’t quote it to them. A second permission system is how leaks happen, because nobody maintains it.
  2. Keep sensitive files out entirely. Fund documents, investor records, tax files. Exclude them by folder or label at the point where documents are loaded. Asking the model to be careful with them is not a control.
  3. Require a source for every answer. Each answer points to the file and page. An answer with no source gets rejected. Anyone can check an answer by opening the file.
  4. Keep one approved copy of each shared prompt. Give it a named owner. Otherwise you end up with six versions and no way to tell which is current.
  5. Cap the cost of every run. A loop that misreads a folder can run up a large bill before anyone notices.

Where to start

Pick one team and one shared folder. Write ten questions that team really asks. Load only that folder, and check every answer against its file.

The first problem is usually the files. Old versions sit next to new ones and the system quotes the old one. Fix the files and the permissions, then widen the scope.

What it won’t do

It doesn’t make decisions and it won’t fix messy file names. It’s only as good as the documents it can read.

Agents

A programmatic agent is software that takes over one repeating job, runs it the same way every time, and sends a person only the exceptions.

The kind of job it fits

  • A daily data file that has to be checked before it’s published
  • A weekly report stitched together from three systems
  • An analyst’s spreadsheet rules, rewritten as tested code

How we build one

  1. Start with the person who does the job. They walk us through the inputs, the decisions and what a correct result looks like.
  2. Write the rules down, exceptions included. If nobody can write the rule down, the job isn’t ready to automate.
  3. Let the clear cases run. They go start to finish on their own. Anything odd is held for a named person, with the reason.
  4. Keep a record of every run. What came in, what went out, who approved it and when.

Why it stays cheap to run

Most of the steps are ordinary code. A model only gets called where a step needs judgment, like flagging a number that looks wrong. So the running cost is hosting plus a few model calls.

We price the build as a fixed fee. We don’t charge per run.

It’s yours

You can buy the code outright: the source, the documentation and the right to change it. If you’d rather we keep running it, we can license it instead.

Each agent has a documented interface, so whatever AI your company uses can call it as a tool. If you switch AI vendors, the agent keeps working.

Private AI

Private AI puts your company’s documents in one private system your team can ask questions. Each person sees only what they could already open, and every answer points to the file it came from.

Questions it’s for

  • “What did we tell this client last year?”
  • “Which deals did we pass on, and why?”
  • A new hire’s questions, without pulling a partner off a deal

How we build it

  1. Your permissions. Access follows the folder rights you already have. Nobody sees a file through the AI that they couldn’t open themselves.
  2. Sensitive files stay out. Some documents shouldn’t reach the model at all. We exclude them at the point where files are loaded.
  3. Every answer has a source. Each one points to the file and page. An answer with no source doesn’t get shown.
  4. Start small. One team, one shared folder, ten real questions. We check every answer against its file, then widen.

Longer version: How do I build an AI brain for my company without exposing client files?

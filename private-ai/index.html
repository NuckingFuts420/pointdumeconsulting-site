Private AI: how we build a firm's AI brain

Private AI puts your firm's documents and history in one private system your team can ask questions, with each person seeing only what they could already open. Sensitive files can be kept out entirely, and every answer points to the file and page it came from.

For example

  • “What did we tell this client last year?”
  • “Which deals did we pass on, and why?”
  • A new hire's questions, without pulling a partner off a deal

How we build it

Most firms' knowledge sits in shared drives, inboxes and people's heads. We turn it into one private system the team can ask in plain English:

  • Your permissions, not ours. Access follows the folder rights you already have. Nobody sees a file through the AI that they couldn't open themselves.
  • Sensitive files stay out. Fund, investor and tax documents can be excluded from the model entirely.
  • Every answer has a source. Each answer points to the file and page it came from. An answer without a source gets rejected.
  • Your team's own tools, kept in order. Where people have built their own AI helpers, we put one approved version of each in a shared library with an owner.
  • A cost cap on every run.

Questions it answers: “What did we tell this client last year?” · “Which deals did we pass on, and why?” · A new hire's questions, without pulling a partner off a deal.

How every project is built

  • Each build starts from the client's market, deal size and buyer.
  • Every row says where it came from: a record we read, a name we classified, or a proxy.
  • If we couldn't read an account, it's marked "not checked". It never shows up as "no signal".
  • Before delivery, an audit re-checks our numbers and we cut any claim that fails.
  • No per-run or per-outcome pricing: you pay for the build and a flat monthly fee for support, and every run has a spending cap.
  • You can buy the code outright, so what we build becomes your company's own.

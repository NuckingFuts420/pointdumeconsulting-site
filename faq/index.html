Questions about Point Dume Consulting

What does Point Dume Consulting do?

We build AI that does real work. In practice that’s four things: account targeting, agents that each run one repeating job, an AI operating layer across a company’s systems, and private AI that answers from a company’s own documents.

What is account targeting?

We write down what your sellers look for in a good account, check every account in your market against those rules using public records, and rank the list. Every row shows its evidence and how we know it: a record we read, a name we classified, or a stand-in measure.

What is a programmatic agent?

Software that runs one defined, repeating job from start to finish, like a weekly report or a daily file check, and sends a person only the exceptions.

What is an AI operating layer?

A company’s data in one place, with the systems it already uses connected, so the team can ask questions and get work done from one window. Work then gets automated one department at a time.

What is private AI?

A system that answers questions from a company’s own documents. Access follows the permissions already in place, sensitive files are kept out, and every answer points to its source.

Do we own the code you build for us?

You can. We’ll sell you the code outright, with the documentation and the right to change it. If you’d rather we keep running it, we can license it instead.

How do you price?

A fixed fee for each phase, agreed before work starts, with the tests that phase has to pass written down. We don’t charge per run.

Can our company’s AI assistant use the agents you build?

Yes. Each agent has a documented interface, so an assistant can call it as a tool. The agent keeps its own checks and its own log, and it keeps working if you change AI vendors.

Which industries do you work with?

Commercial real estate, ERP consulting and healthcare M&A so far. The approach carries to any market that leaves public records, and to any job a team repeats.

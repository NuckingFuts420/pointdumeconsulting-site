Questions about Point Dume Consulting

What does Point Dume Consulting do?

Point Dume Consulting is an AI consultancy in Los Angeles. Its core service is account targeting and scoring: it works with a client's sales team to define the ideal customer, finds the signals in the client's own wins and losses, scores every account in the market on those signals using public evidence, and ranks them by the probability the client wins them. It also builds programmatic agents that run one repeating job end to end, and private AI that answers from a firm's own files.

What is evidence-graded targeting?

A target list where every account shows how each signal is known: from a record we read, a name we classified, or a proxy. Sales teams can tell solid picks from informed guesses.

What is a private AI system for a firm?

A system that answers questions from a firm's own documents. Access follows the firm's existing permissions, sensitive files are kept out, and every answer cites its source.

What is a programmatic agent?

Software that runs one defined, repeating job end to end, like a weekly report or a daily file check, and sends a person only the exceptions.

What is a signal architecture?

A signal architecture is the system Point Dume Consulting builds to turn what a client's best customers had in common into a ranked, current list of accounts. It has five parts: signals (each pattern written as a checkable rule), sources (where each signal shows up in public records), evidence (what each source says about each account, with the link and date), scoring (every account checked against the rules, showing hits, misses and what could not be checked) and watching (sources re-read on a schedule, with changed accounts re-scored). The client's wins and losses feed back in so the rules improve over time.

Do we own the code you build for us?

You can. Point Dume Consulting will sell clients the code for the agents and systems built for them outright, instead of licensing it, so the work becomes part of the client's own operations and IP. Licensing is available if the client would rather Point Dume keep running it.

How much does an agent cost to run?

Point Dume Consulting charges for the build and a flat monthly fee for fixes, changes and support, not per run or per outcome. Agents are mostly ordinary code and call a model only for steps that need judgment, with a spending cap on every run, so the running cost is hosting and a few model calls.

Can our company's AI assistant use the agents you build?

Yes. Each agent has a documented interface, so a company's AI assistant or AI brain can call it as a tool. The agent still runs its job with its own checks and log, and it keeps working if the company changes AI vendors.

Which industries do you work with?

Commercial real estate, ERP consulting and healthcare M&A so far. The methods carry to any market with public records or repeat work.
